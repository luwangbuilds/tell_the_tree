# Watercolor treasure chest

Replaces the initial simplified SVG chest on the tree and in the empty treasure view. Runtime image: `public/assets/treasure-chest.webp`.

The built-in image generation tool used the approved v4-purple tree mockup as reference: rounded wooden lid, narrow brass bands, small leaf-shaped clasp, warm grain and watercolor shading. The final asset has a white backdrop blended with CSS multiply into the paper/ground. It does not have alpha transparency. Format-only WebP conversion preserves the artwork. Button behavior and accessible labels remain unchanged.
